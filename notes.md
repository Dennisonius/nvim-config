#### Сочетания клавиш

'y' - копирование; 'p' - вставка  
<C-w> - для управления переходом между окнами (перед ней можно ввести цифру):  
'h', 'j', 'k', 'l' - в сторону какого окна перейти  
'+', '-', '\_', '=', '<', '>' - управление размером окон

#### Команды

`:set number` - включение номерации строк  
`:Lazy` - Для управления плагинами  

#### Как работают плагины в nvim

Плагины не нужно специальным образом устанавливать. Просто файл с плагином  
кладется в правильную папку, обычно `~/.config/nvim`. Дальше на этапе загрузки
nvim сам проверяет эту папку и забирает все плагины.

Для лучшего распространения и управления разными плагинами используются
менеджеры плагинов. Здесь используется [lazy.nvim](https://github.com/folke/lazy.nvim).
