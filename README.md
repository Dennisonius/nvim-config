### My Neovim config in lua

[Neovim](https://github.com/neovim/neovim)

#### What I have
 - Plugins managed by [lazy.nvim](https://github.com/folke/lazy.nvim)
 - Some cosmetic plugins for nvim
 - Keymaps with `space` as leader key
 - Plugins for file explorer [nvim-tree](https://github.com/nvim-tree/nvim-tree.lua) and file/general search [telescope](https://github.com/nvim-telescope/telescope.nvim)
 - [LSP configs](https://github.com/neovim/nvim-lspconfig) for c, cpp, python, lua and neocmake [treesitter](https://github.com/nvim-treesitter/nvim-treesitter)
 - [Mason](https://github.com/mason-org/mason.nvim) for managing LSP servers, linters and formatters
 - Git plugins [fugitive](https://github.com/tpope/vim-fugitive) and [diffview](https://github.com/dlyongemallo/diffview-plus.nvim)
